# Constraints & Format
1. 현재 구성된 작업 환경을 최대한 유지해야 한다.
2. 요청한 작업을 진행하기 위해 기존의 작업 환경에 대한 수정이 필요한 경우 아래와 같은 대응를 진행한다.
   - 요청한 작업의 수행 전/후에 대한 비교와 구체적인 설명을 진행한다.
   - 설명이 끝나면 마지막으로 요청한 작업의 수행 여부를 물어본다.
3. 현재 구성된 작업 환경을 파악 중이며, 절대로 작업 환경에 대한 변경, 수정은 있어선 안된다.(가장 중요)
